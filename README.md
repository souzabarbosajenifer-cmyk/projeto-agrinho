# EcoProdutor - Diagnóstico Sustentável

Projeto desenvolvido para o concurso Agrinho.

 ## Como Acessar

 Abra o site pelo GitHub Pages.

 ## Como Utilizar 

 1. Acesse a página inicial.
 2. Responda às perguntas sobre a propriedade rural.
 3. Clique no botão para gerar o diagnóstico.
 4. Leia as recomendacões de sustentabilidade apresentadas pelo sistema.
 5. Reinicie o questionaário caso deseje realizar uma nova análise.

## Tecnologias Utilizadas

- HTML
- CSS
- JavaScript

## Objetivo

O EcoProdutor auxilia produtores rurais a identificar práticas sustentáveis e oferece orientações para melhorar a gestão ambiental da propriedade.
